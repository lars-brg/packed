# Packed 

O **Packed** é uma aplicação web progressiva (PWA) voltada ao planejamento e à organização de bagagens para viagens. A partir do destino, do período da viagem e das atividades planejadas, o sistema consulta informações meteorológicas e utiliza regras de recomendação para gerar uma lista personalizada de itens para levar.

O objetivo é simplificar a preparação da bagagem, reduzir o esforço de planejamento manual e permitir que o usuário acompanhe os itens separados antes de viajar.
